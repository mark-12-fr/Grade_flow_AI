# GradeFlow AI

Report cards, SF10 records and class rankings for Senior High School (Grades 11–12), built for a client demo.
The teacher uploads the spreadsheet they already have, in any layout. AI works out which column is which, and the teacher only reviews.

## How the AI import works

1. The browser sends the Excel/CSV to `POST /api/import`.
2. The server sends **only the top ~15 rows** and the list of target fields to the AI model, which answers with a column mapping (JSON).
3. **Code, not the model, copies every value** from the sheet using that mapping. No grade is ever generated by AI; blank stays blank.
4. The teacher reviews the result in *Grade Verification* (the "How AI read your file" panel shows each mapped column and any warnings).

If the backend or API key is unavailable, the app falls back to the built-in template reader, so the demo never dies.

## Run locally

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then put your key in .env, or export it:
export AI_API_KEY=...   # free key, see .env.example (Gemini / Groq / OpenRouter; Ollama needs none)
uvicorn backend.main:app --reload
```

Open http://127.0.0.1:8000 and upload `samples/messy_class.xlsx` (fictional learners, non-template headers).

## Keeping the API key and the bill safe

- The key lives only in `.env` (git-ignored, mode 600) on the server. The browser never sees it and `/api/health` only says whether it is set.
- Never put the key in `.env.example` (that file is committed). Do not paste it in chat, issues or screenshots.
- Limits (see `.env.example`): per-visitor rate limit, a daily cap on AI calls for the whole server, a max number of sheets per SF10 upload and a max sheet size. Over the limit the API answers 429/422 with a clear message and **no AI call is made**.
- Set `APP_ACCESS_CODE` when anyone else can reach the server; the app asks for the code once per browser session.
- Run `uvicorn backend.main:app --host 127.0.0.1` (the default) unless you deliberately expose it.
- Also set a quota/expiry on the key in your provider's console if it offers one. Free tiers stop at their quota instead of charging you.

## Pages

Upload → Processing → Verification (grades, attendance, observed values) → Report card preview (SF9 with Passed/Failed remarks) → Print/PDF, plus **SF10 Record** (per learner or whole class, PDF) and **Summary & Rank** (class stats, ranking with ties, CSV export).

## Tests

```bash
pytest backend
```

The AI call is mocked in tests; they cover column mapping, value copying, footer rows, validation and the API.

## Hosting

No hosting is configured in this repo. The frontend is plain static files (`index.html`, `css/`, `js/`, `assets/`), so it can be hosted anywhere, e.g. Vercel.

The AI import needs the FastAPI app (`uvicorn backend.main:app`) running somewhere with `AI_PROVIDER` and `AI_API_KEY` set (free providers, see `.env.example`). On a static-only host, uploads fall back to the built-in template reader.

## Notes

- Use **fictional data only** for demos: learner names and LRNs are sent to the AI provider during import. Free tiers (e.g. Gemini free) may use submitted data to improve their models; for real learner data use Ollama (runs locally) or a paid plan with data-use disabled.
- Nothing is persisted; a page refresh clears the session.
- Only the first/largest sheet of a workbook is read; other sheets are listed as warnings.
