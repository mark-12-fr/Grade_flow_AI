# GradeFlow AI

Report cards (SF9) and permanent records (SF10) for Senior High School (Grades 11–12).
The teacher uploads the spreadsheet they already have. AI reads it, and the teacher previews the SF9 and SF10 for any learner (picked by LRN) and downloads or prints the PDFs.

Built with **Next.js (App Router) + React + TypeScript**. The AI import runs in Next.js API routes, so there is one app and one command to run.

## Run it

```bash
npm install
cp .env.example .env     # then put your free AI key in .env
npm run dev              # http://localhost:3000
```

Production: `npm run build && npm start`.

Free AI keys (pick one provider in `.env`): Gemini https://aistudio.google.com/apikey, Groq https://console.groq.com/keys, OpenRouter https://openrouter.ai/keys. Ollama (https://ollama.com) needs no key and runs on your own computer.

## How the AI import works

1. **SF9** (`POST /api/import`): the server sends only the top ~15 rows and the list of target fields to the AI, which answers with a column mapping (JSON). **Code, not the model, copies every value** from the sheet. No grade is generated by AI; blank stays blank. If the AI is unavailable, the built-in template reader is used.
2. **SF10** (`POST /api/import-sf10`): an SF10 is a form, so the AI reads the whole sheet (one learner per sheet) and returns the record. Every grade it returns is checked against the sheet's own cells; a value that is not in the sheet is dropped.

## Keeping the key and the bill safe

- The key lives only in `.env` (git-ignored) on the server. The browser never sees it and `/api/health` only says whether it is set.
- Never put the key in `.env.example` (that file is committed). Do not paste it in chat, issues or screenshots.
- Optional limits (all **off** by default, see `.env.example`): per-visitor rate limit, a daily cap on AI calls for the whole server, a max number of sheets per SF10 upload and a max sheet size. Over a limit the API answers 429/422 with a clear message and **no AI call is made**. Turn them on before sharing the server or when using a paid key.
- Set `APP_ACCESS_CODE` when anyone else can reach the server; the app asks for the code once per browser session.
- Free tiers may use submitted data to improve their models. Use **fictional data only** for demos; for real learner data use Ollama or a paid plan with data use disabled.

## Project layout

```

src/app/api/        import, import-sf10, health
src/components/     Shell, Providers (toast + modal), ReportCard (SF9), Sf10Sheet (SF10), Icon
src/lib/            curriculum, grading, store, actions, sf10Record, pdf/ (jsPDF drawing for SF9 and SF10)

tests/              vitest tests for the server code
samples/            fictional sample workbook and the script that builds it
public/reel/        27-second promo reel (plain HTML/CSS/JS)
scripts/            render-reel.mjs (turns the reel into an MP4)
```

## Promo reel

`public/reel/index.html` is a 27-second, 1920×1080 promo with six scenes: identity, promise, how to use, why it matters, no guessing, and the closing card. It uses only fictional learners.

- **Watch it:** run `npm run dev` and open http://localhost:3000/reel/index.html, or just open the file in a browser. Keys: Space play/pause, ← → seek, R restart, F fullscreen.
- **Options:** `?url=your-app.vercel.app` puts your address in the closing pill. `?once` plays it once instead of looping.
- **Export an MP4:** `npm run reel` writes `gradeflow-ai-reel.mp4` (needs Playwright with Chromium and ffmpeg). Every frame is drawn at an exact time, so the video has no dropped frames. `npm run reel -- out.mp4 --fps 60 --url your-app.vercel.app` changes the defaults, and `npm run reel -- --still 12.5 frame.png` saves one frame.
